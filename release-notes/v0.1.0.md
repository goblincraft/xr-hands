# Release Notes: v0.1.0

This release establishes the core hand tracking foundation for the xr-hands library by integrating TensorFlow.js and establishing the webcam capture pipeline.

## What's New

*   **Dependency Management**: Added `@tensorflow/tfjs` and `@tensorflow-models/hand-pose-detection` to the project for hand pose detection capabilities.
*   **Type Definitions**: Introduced the `HandPose` interface in `src/core/types.ts` to standardize 3D keypoints (x, y, z coordinates) and confidence scores returned by the model.
*   **Webcam Integration**: Implemented webcam initialization logic in `HandTracker.init()` using the browser's MediaDevices API, including proper error handling for missing permissions or hardware.
*   **Model Initialization**: Added the ML model loading mechanism to instantiate the TensorFlow.js hand-pose-detection model during initialization.
*   **Prediction Loop**: Implemented `HandTracker.estimateHands()` to process video frames, map raw model outputs to the standardized `HandPose` structure, and support clean stopping.
