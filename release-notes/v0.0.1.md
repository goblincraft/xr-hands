# Release Notes: v0.0.1

This initial release establishes the foundational setup for the xr-hands library.

## What's New

*   **Project Initialization**: Initialized the Node.js project using npm and configured `package.json` with basic metadata.
*   **Infrastructure & Build Tools**: 
    *   Added `typescript` and `parcel` as development dependencies.
    *   Configured TypeScript (`tsconfig.json`) with strict typing rules, `node` module resolution, and `ESNext` target.
    *   Configured build (`parcel build`) and dev (`parcel serve`) scripts.
*   **Core Architecture**: 
    *   Established the core source directory structure: `src/core`, `src/render`, and `src/utils`.
    *   Created the base library skeleton including empty `HandTracker` and `HandMeshRenderer` classes.
    *   Added the main `index.ts` entry point exporting the core classes.
*   **Documentation & Planning**: 
    *   Created an `implementation` directory to track sprint plans.
    *   Documented the v0.0.1 sprint plan.
